# All-weather RFID bee returns × wind: independent observation-channel test

**Protocol frozen:** 2026-11-22, before inspecting raw RFID event counts or wind-effect associations. This is a **new exploratory secondary analysis of existing Karbassioon & Stanley data**, not an independent study, not an original-source prior-art result, not a TNOA field observer performance experiment, and not prospective confirmation.

## Biological target and why it matters

The prior Irish oilseed-rape field-visit analysis had a cross-day wind relationship that changed direction or lost support after date conditioning. The archived source separately includes **all-weather nest-entry RFID for honeybees and bumblebees**, and 30-second contemporaneous weather. The new question is:

> Within recording days, is variation in wind associated with different rates of **observed tagged-bee nest returns** for honeybees and bumblebees, after controlling for the diurnal cycle and temperature?

This directly concerns a bee behavioral process (foraging-related nest returns) but is **not** a direct measurement of field-flower visitation, flowers contacted, or pollination effectiveness. It is a complementary behavior channel within the SAME source study, not external-research replication.

The original metadata says RFID nest activity from **1–31 July 2021**, captured in all weather. Three colonies per bee group; tags observed: **182 bumblebee workers** and **199 honeybee foragers** (the original study cautions about missed RFID tags, especially honeybees). A bee return represents a proxy for foraging trip returns, not exact food-resource acquisition. Weather measured every 30 s near colonies. The oilseed rape field surveys used separate sites and deliberately favorable weather; these domains cannot be pooled as if one experiment or contrasted causally.

## Admission gate before examining wind responses

1. Retrieve all three original CSVs directly from the publisher's Zenodo file endpoint, verify exact MD5, compute SHA256 and log source field names, row counts, date support, categories and event identifiers. No raw CSV may be pushed to GitHub or included in artifact ZIPs.
2. `direction` must contain an unambiguously documented arrival code; `uid`, `collection`, event timestamp fields and repeated RFID rows must be interpretable. If `direction` cannot be distinguished or no valid event time exists, **HOLD**.
3. Require at least 12 calendar days with BOTH taxa and wind, >15 unique detected tags per taxon, >=20,000 valid weather rows and >50 weather observations/day during qualifying dates. Verify distinct colony representation, clock timezone/civil formatting, duplicate RFID timestamps and no anomalous future timestamps. Event handling is exactly **one arriving-tag event per tag per >=5 minute gap** as in original methodology. Never convert an unknown direction to an arrival.
4. Publish source-only receipt and incidence/coverage gate before fitting wind effects. If the pairing between 30-s weather rows and RFID timestamps is invalid, **HOLD**, no interpolation across missing days.

## Defined biological estimands and interpretation

- **Observed nest return intensity**: for each taxon and each 15-minute daytime interval, count unambiguously arriving distinct-tag events after the 5-min same-tag de-duplication. Count zero-arrival intervals when RFID logging coverage is independently documented or reliably reconstructible; otherwise label the estimator as *observed returns per calendar-bin* with uncertain detector uptime. This is not total nest arrival intensity or population-level foraging.
- **Common weather exposure**: mean original `windspd` for the same 15-minute civil bin from 30-s station records. Retain mean `temp`, `solar`, `rh` and rain covariates if sufficiently complete. No exposure imputation from next or previous dates.
- **Grouping and time controls**: date fixed effects plus local clock-hour quadratic or cyclic basis, and taxon × clock interaction (bee guilds differ in diel activity in source publication). Weather exposure is shared across taxa within same bin; pair matching at 15-minute bins avoids testing differences merely caused by different sampling time.
- **Primary ecological contrast**: whether the *within-day wind slope* of observed nest return rate differs between honeybee and bumblebee, after matching the SAME 15-min time periods. Fit a count model using an exposure offset only if the tagged activity sampling denominator is demonstrably comparable within a taxon. A taxon×wind interaction is the primary statistic; taxon-specific weather slopes are secondary/descriptive.
- **Time-block null**: 999 whole-15-min bin wind permutations within each day (shuffle both taxa's shared wind label together), fixed RNG `20261122`, preserving date, tag counts and original taxon counts. Must establish enough day-level exchangeable windows, and test 15–30min blocks/temporal autocorrelation as sensitivity. If exchangeability is not credible within days due diurnal wind patterns, reject a causal reading.
- **Environmental sensitivity**: add temperature, sunlight and rain; do not label wind coefficient as independently causal if multicollinearity limits support. Check excluding days dominated by RFID downtime or tagging intervals only if such metadata are available.
- **No p-hacking**: freeze candidate endpoints, 5-minute gap, 15-minute bins, at least 12 days, 999 permutations and code version before inspecting outcome directions; no cutoffs selected for positive effect. Report both positive and adverse outcomes.

## Claim ceilings

This is a **second sensor/behavioral endpoint within the same published Irish study**, not independent biological study replication. Nest RFID and flower transects are not contemporaneous observational units or identical populations and cannot establish that one is a direct correction of the other. 199/182 observed tags are not independent wind replicates, three colonies per taxon are limited, RFID tag detection and antennal coverage can differ, and 30-s weather samples are not 30-s independent biological trials. No wild plant reproduction, pollen transfer, causal wind treatment or universal TNOA biological-process law may be inferred.

If the data allow an effect, call it an **exploratory within-source field-behavior association**; if not, publish a clear scientific HOLD or null. The frozen TNOA MEE Paper 1 and the already merged Irish/Wyoming sidecar remain unchanged.
