# MEE submission formatting provenance

This document records the non-scientific conversion of the audited anonymous MEE manuscript source into a Word submission file. The formatting pipeline does not change observer definitions, frozen results, post-freeze analyses or scientific claims.

## Canonical manuscript source

`submission/generated/MEE_INITIAL_SUBMISSION_SOURCE.md` is generated by `scripts/build_mee_initial_submission_source.py`. It contains the numbered abstract, the active MEE body, the `Materials and Methods` heading, figure callouts and captions, and no internal C/D provenance comments.

## Citation rendering

The current Citation Style Language repository records `Methods in Ecology and Evolution` as a dependent author-date style whose independent parent is APA. For deterministic CI conversion, TNOA pins the official CSL styles repository to commit:

`2a4430b7cadae7cc88012537c5ceaed76d1d9938`

and uses the independent parent:

`apa.csl`

with Git blob SHA-1:

`9bc45ef6289bb2f933a0fd9a44640baa34a3191e`

The dependent MEE style file at that commit is:

`dependent/methods-in-ecology-and-evolution.csl`

and explicitly points to `http://www.zotero.org/styles/apa` as its independent parent. Pandoc citeproc receives `references.bib` plus the pinned independent CSL to render in-text citations and the References section. The final publisher-formatted reference appearance must still be visually inspected before upload.

## DOCX build

`scripts/build_mee_submission_docx.py`:

1. regenerates the canonical anonymous source;
2. renders Markdown citations/references through Pandoc citeproc;
3. opens the generated DOCX with `python-docx`;
4. applies double paragraph spacing to paragraph styles;
5. sets one-inch margins;
6. enables continuous line numbering (`countBy=1`, `start=1`, `restart=continuous`);
7. registers page numbering from 1 and inserts a PAGE field in the footer;
8. sets document creator and last-modified-by properties to `Anonymous`.

## DOCX validation

`scripts/validate_mee_submission_docx.py` inspects the zipped Word XML directly and fails unless it finds:

- a rendered active MEE title, `Materials and Methods`, Results, Discussion, References and figure captions;
- no raw Pandoc citation syntax;
- an anonymous identity scan;
- Normal-style double spacing (`w:line=480`, automatic line rule);
- continuous line numbering in every section;
- page numbering beginning at 1 plus a footer PAGE field;
- anonymous core document metadata;
- a conservative visible-word guard between 3,000 and 8,000 words.

## Remaining human check

The generated DOCX is an initial-submission candidate, not a substitute for a final visual review. Before upload, inspect page/line-number rendering in Word or a compatible viewer, typography, page breaks, reference appearance, equation rendering and figure-caption placement. Recheck the publisher-facing word count because journal and word-processor counting conventions may differ from the repository guards.
