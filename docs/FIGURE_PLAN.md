## Figure 1 — TNOA observation ontology and decision entitlement

Conceptual figure, no quantitative result.

### Panels

A. World/process layer: baseline plus potentially co-occurring target and nuisance processes.

B. Evidence layer: T / optional attributed C / N / O / optional A− kept as separate channels.

C. Decision layer: B / T / N / U with T+N superposition preserved diagnostically rather than collapsed into mutually exclusive natural classes.

D. Development layer: definition defect → representation defect → information/no-support → process coupling, with freeze-before-measurement and retained negative generations.

### Main message

TNOA is not a rejector attached to one classifier. It is a process-preserving observation contract that determines which biological statements are licensed by the available measurement channels.

### Claim IDs

C1, C4, C14, C15.
